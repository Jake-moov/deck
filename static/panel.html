Como conectar

  1. Deixe o celular na mesma rede Wi-Fi do PC.
  2. Aponte a câmera para o QR code e abra o link.
  3. No navegador do celular, escolha Adicionar à tela inicial para usar como app em tela cheia.
Se o Windows perguntar sobre o Firewall, permita o Deck em redes privadas.

Segurança

Exigir PIN no celular
Sem PIN, qualquer aparelho na mesma rede consegue usar seus botões.
